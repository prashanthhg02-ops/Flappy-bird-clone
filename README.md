# Sky Hopper

A small Flappy Bird-style game that runs directly in your browser. It uses
HTML, CSS, and the Canvas API, with no dependencies or build step.

## Play

Open `index.html` in a modern web browser, then select **Start Flying**.

- **Space**, **Up Arrow**, click, or tap to flap
- **P** to pause or resume
- Avoid the pipes and the ground to keep flying
- Your best score is saved in your browser

## Run locally

You can open `index.html` directly, or serve this folder with any static file
server. For example, if Python is installed:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.
